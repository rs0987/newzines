# NewZINES (Rails アプリ)

## 技術スタック

- Ruby 4.0 / Ruby on Rails
- PostgreSQL 18
- Tailwind CSS
- ホスティング: Render

## 開発環境

開発は VS Code の Dev Container で行います。手元に Ruby や PostgreSQL を入れる必要はありません。

### 前提

- Docker Desktop
- VS Code と拡張機能「[Dev Containers](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)」

### セットアップ

1. VS Code で `web/` フォルダを開きます（リポジトリのルートではありません）
2. コマンドパレットから「Dev Containers: Reopen in Container」を実行します

初回は `bin/setup` が自動で実行され、gem のインストールとデータベースの作成まで行われます。

### 起動

コンテナ内のターミナルで次を実行します。

```sh
bin/dev
```

http://localhost:3000 で開けます。

開発環境では、seed で作られる管理者（ユーザー名 `admin`、パスワード `password12345678`）で管理者サイトにログインできます。

### コードの整形

Ruby ファイルは、保存時に RuboCop（rubocop-rails-omakase）のルールで自動整形されます。Dev Container を開くと、必要な拡張機能（Ruby LSP）と設定が自動で入ります。

## 用語集

概念と、コード上の名前の対応です。新しい概念を追加するときは、先にここに書いてから実装します。

### 人と役割

| 日本語 | コード | 説明 |
| --- | --- | --- |
| 管理者 | `Administrator` | サービス全体を管理する人。スタジオとライターを管理する。 |
| アカウント | `Account` | ライターや読者としてログインする主体。ログイン情報を持つ。 |
| ライター | `Writer` | アカウントが持つ役割の一つ。スタジオに所属し、参加している ZINE に記事を書く。 |
| 読者 | `Reader` | アカウントが持つ役割の一つ。ZINE にコメントを書く。 |

### スタジオと ZINE

| 日本語 | コード | 説明 |
| --- | --- | --- |
| スタジオ | `Studio` | テーマのもとに集まったライターのグループ。ZINE を発行する単位（テナント）。 |
| スタジオメンバー | `StudioMembership` | ライターとスタジオをつなぐ。役割はオーナー（`owner`）かメンバー（`member`）。 |
| ZINE | `Zine` | 一つのテーマを持ったページのまとまり。発行したスタジオが最終的な責任を持つ。 |
| 責任編集者 | `Zine#editor` | ZINE に一人だけいる責任者。スタジオのメンバーから選ぶ。ページの確定と ZINE の発行を行う。 |
| ページ | `Page` | ZINE の中の1枚1枚。タイトルと本文を持ち、担当ライターが一人いる。 |

| できること | オーナー | メンバー |
| --- | --- | --- |
| スタジオのメンバーを管理する | ○ | × |
| ZINE を作り、責任編集者を付け替える | ○ | ○ |
| ページを作り、担当ライターを決め、並べ替える | ○ | ○ |

| できること | 責任編集者 | 担当ライター |
| --- | --- | --- |
| 自分が担当するページを書き、提出する | － | ○ |
| ページを確定・差し戻しする | ○ | × |
| ZINE を発行する | ○ | × |

- ZINE は、小さな組織を想定し、スタジオのメンバーなら誰でも作れて扱える。オーナーは ZINE について特別な権限を持たない
- 責任編集者は一人。最初は ZINE を作った人がなり、あとからスタジオのメンバーなら誰でも付け替えられる
- ページの担当ライターは、スタジオのメンバーでなくてもよい
  - 将来、スタジオの外のライターにページを頼めるようにするため
- ライターはスタジオに所属しなくても存在できる
  - スタジオを作ってオーナーになるか、招待されてメンバーになる

### サイト

画面の集まりを「サイト」と呼ぶ。一つひとつのページ（ログイン画面など）は「画面」と呼んで区別する。

| 日本語 | 名前空間 | URL | 主に使う人 |
| --- | --- | --- | --- |
| 管理者サイト | `Admin::` | `/admin/...` | 管理者 |
| スタジオサイト | `Studios::` | `/studios/:slug/...` | ライター（管理者も見られる） |
| 公開サイト | なし | `/zines/...` など | 読者 |
